# Úvod

Vítejte v ukázkové dokumentaci! Toto je testovací projekt pro demonstraci převodu Docusaurus do PDF s podporou češtiny.

## Co se naučíte

Tato dokumentace pokrývá:

- **Začínáme**: Instalace a základní nastavení
- **Pokročilá témata**: Přizpůsobení a strategie nasazení
- **API Reference**: Kompletní API dokumentace

## Rychlý příklad

Zde je jednoduchý příklad kódu:

```javascript
function hello() {
  console.log('Ahoj světe!');
}
```

## Důležité poznámky

:::note
Toto je důležitá poznámka, která by měla být zvýrazněna v PDF výstupu.
:::

:::tip
Profesionální tip: Použijte mód `per-section` pro generování samostatných PDF pro každou hlavní sekci.
:::

## Funkce

1. **Moderní LaTeX**: Používá engine Tectonic pro rychlou kompilaci
2. **Dockerizované**: Žádná lokální instalace LaTeXu není potřeba
3. **Flexibilní**: Jedno PDF nebo PDF podle sekcí nebo jazyků
